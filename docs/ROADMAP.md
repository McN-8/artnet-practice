# ArtNet Roadmap

**Status:** Sequencing guide, not a delivery commitment. Current implementation is documented in [TECHNICAL_SPEC.md](TECHNICAL_SPEC.md).

## Present architecture

The TypeScript prototype has a versioned project format, state and prompt runtime, asset and audio contracts, traditional presentation data/navigation, auto-prompt timing controls, reusable visual/effect resource types, and tests. These are foundations, not evidence that a complete editor, hosted community, or production player exists.

## Near-term product work

1. Complete the production reader path for traditional pages and interactive states, including rendering, inputs, asset readiness, and accessible controls.
2. Create a simple import, arrange, preview, and publish editor flow; add grid, alignment guides, reversible snapping, and core object transforms.
3. Expose reader auto-prompt controls and test pacing, pause/skip, and backward restoration in the actual interface.
4. Prototype layered panels, moving viewports, looping backgrounds, and scoped blur only after baseline reading is dependable.

## Later product work

Build the frame-sequence timeline, adaptive audio variants, particle/random motion and scatter presets, Apple Pencil interactions, and device haptics through focused proposals and small proofs. Develop discovery, content filtering, and community systems with rights, privacy, and moderation design.

## Long-term ideas

Achievements across reading, creating, community, and exploration; layered non-invasive notifications; community voiceovers; Easter eggs; loading-screen tips if load times warrant them; deeper recommendation experiments. None should be treated as shipped or as a reason to delay the core creation and reading path.
